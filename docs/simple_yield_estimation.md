# 自动简化估产：小麦、玉米试验任务

## 模拟演示（2026-10-13）

实时工作台选择影像和估产任务后，可以在“估产模拟演示”中选择小麦或玉米，点击“演示估产与报告”。也可明确告诉助手“用模拟数据演示玉米估产”。支持 `yield_simple` 和 `yield`，演示请求仅选择估产任务；影像、作物、LAI 等依赖步骤会自动生成演示记录，不调用真实计算。普通“开始执行”仍走原有数据链路，数据不足不会自动替换为模拟结果。

模拟方法版本为 `synthetic_yield_demo_v1`。小麦示例单产为 6.20 t/ha、示例范围 5.40–7.00；玉米为 9.10 t/ha、示例范围 8.00–10.20。单位为粮食干重，范围为预设展示值。总产量仅用当前 AOI 面积乘以模拟单产得到。构造逐日 LAI、生物量、子粒重、生长阶段曲线，预设季节取所选影像前一年；这些日期不是实际播收记录，记录数不是遥感观测次数。

后端请求显式使用 `data_mode=demo`、`demo_crop=wheat|maize`，工作流及步骤保留模拟标识；卡片启动动作使用 `yield_demo_crop`，沿用原有上下文校验、幂等提交、任务历史和所有者权限。实际请求默认 `data_mode=live`，不接受 `demo_crop`。模拟报告复用 `v2/tools/apsim_report_handler.py` 的 APSIM 生长曲线模板，提供指标、三个曲线页签、生长阶段时间轴、参数与数据来源。报告顶部标注“模拟数据 · 仅用于功能演示”，明确未运行 APSIM。结果卡片、聊天回执、总报告及结构化 JSON 同样区分模拟数据。

演示结果中的作物、LAI 和产量均不是当前地块的识别或实测结果，不用于验证估产精度。

日期：2026-10-12。任务标识：`yield_simple`；方法版本：`rue_ndvi_observed_season_v1`。

## 需求与选择

当前没有历史实收产量，用户不能填写播种和收获日期。因此不能训练、验证本地产量回归模型，也不应通过单景冠层指数直接换算产量。新增独立的 RUE 光能利用率任务，由系统读取时序影像和公开辐射，自动识别遥感生长周期，计算粮食干重的试验估计。

APSIM 通常需要逐日气象、分层土壤与初始水分/氮素、作物品种及播种密度/日期、施肥和灌溉等管理信息，还需要适合研究区域的参数与验证数据。官方教程展示了气象文件、初始水分/氮素、播种和施肥设置对模拟的作用：[APSIM 作物模拟教程](https://docs.apsim.info/docs/user-tutorials/module4/modulefourtutorial)。当前服务器未配置 `APSIM_FIELD_MODELS_BIN`、`APSIM_FIELD_RUNTIME_VERIFIED` 和 `APSIM_FIELD_DATASETS_DIR`，无法执行已核验地块的 APSIM 估产。旧 `yield` 任务仍表示 APSIM，历史数据不改名或改算法。

## 用户流程

1. 框选地块、选择影像，选择“自动简化估产（试验）”，或说“执行小麦/玉米估产”。普通估产请求优先推荐 `yield_simple`；明确 APSIM 请求仍使用 `yield`。
2. 自动展开 `imagery → crop → yield_simple`，不要求 LAI 反演、土壤数据集或播收日期。
3. 作物识别支持玉米、春小麦、冬小麦（最终判定为其他作物时返回“暂不支持”并允许改选）。判定以 KDD2020 六类分数为证据，由大模型结合观测日期与地块位置给出最终作物（见 [作物识别判定层](crop_decision.md)）；仅在大模型不可用回退时，才使用首选分数 ≥0.60 且前两名差 ≥0.15 的旧规则。识别不明确或为其他作物时只显示作物下拉框，不展示播种/收获日期输入框。用户确认的是本季地块作物；这也是跨期估产的必要假设。
4. 收集时序影像、云掩膜、公开辐射，自动识别完整生长期并生成结果/报告。当前季节仍在生长、观测缺口过大或气象缺失时返回明确原因，不产生伪造产量。
5. 已完成结果的作物输入不可更改；另起分析。失败可重试，补充作物沿用同一工作流与已完成的识别结果。

## 数据与季节检查

- 截止日期为用户所选影像日期，而非自动使用未来影像；回看 540 天，识别最近一年内结束的完整周期。结果始终显示季节日期，不能把历史季节说成本年预测。
- STAC 有界分页、选区覆盖 ≥95%，整景云量 ≤40%；按日期去重，均衡抽样最多 36 景。实际选区使用 Sentinel L2A SCL 4/5 类掩膜，至少 16 个、覆盖选区 ≥50% 的清晰像元。SCL 与反射率资产共同签名。
- B04/B08 重采样到 20m，采用选区清晰像元 NDVI 中位数；优先显式尺度/偏移，对未提供偏移的 PB≥04.00 原始 DN 使用 BOA 偏移。云影、水体和雪不代入有效 NDVI。[ESA Sentinel-2 处理说明](https://sentiwiki.copernicus.eu/web/s2-processing)
- 最少 8 个合格日期；邻域时间跨度 ≤45 天时使用三点中位数平滑。基线为低分位 NDVI，季节阈值为 `clip(baseline+0.2*(peak-baseline),0.2,0.4)`；峰值 ≥0.45、振幅 ≥0.25。
- 生长期 60～240 天（玉米/春小麦），期间 ≥5 个合格日期，前后均有观测；活跃阶段不得存在 >45 天缺口。不得超出观测首尾外推。
- 冬小麦允许跨年低温休眠合并：间隔 ≤120 天、休眠始于10月至次年2月、间隔日均温完整且均值 <8°C；完整季节须于8～11月开始、4～8月结束，长度150～365天。规则是季节识别启发式，尚未用当地播收记录验证。
- 使用 [NASA POWER Daily API](https://power.larc.nasa.gov/docs/services/api/temporal/daily/) 的 AG 逐日 `ALLSKY_SFC_SW_DWN`（严格核对 MJ/m²/day）和 `T2M`；代表点按0.5°归组用于缓存，不表示地块测站或宣称产品恰好具有0.5°分辨率。缺日和 `-999` 不填补。结果记录请求时期、代表点、来源、单位与响应摘要；缓存原子写入。

## 公式与参数

`APAR = Σ [短波辐射 × 0.48 × clip(1.24×NDVI−0.168,0,0.95)]`

`粮食干重产量(t/ha) = APAR(MJ/m²) × RUE(g干物质/MJ APAR) × HI × 0.01`

光吸收、干物质和收获指数的基本关系参考 [Monteith (1977)](https://doi.org/10.1017/S0021859600056616)。NDVI/FPAR 关系是通用 LUE 模型表达，见该研究的模型汇总表：[Agricultural and Forest Meteorology (2025), Table 3](https://ris.utwente.nl/ws/portalfiles/portal/476367457/1-s2.0-S0168192324004891-main.pdf)；它不是本地小麦/玉米专用标定。

| 作物 | RUE 默认与情景范围（g/MJ APAR） | HI 默认与情景范围 |
| --- | --- | --- |
| 玉米 | 3.3；3.1～3.51 | 0.50；0.40～0.55 |
| 春/冬小麦 | 2.5；2.2～3.0 | 0.50；0.40～0.53 |

小麦研究记录了全季与抽穗前不同 RUE、不同条件下 HI；玉米参数参考 [小麦/玉米辐射利用研究](https://doi.org/10.1016/j.agrformet.2015.02.004)。表中的默认值与上下限是参考文献启发的试验配置，**并非一套已发表且经过本地验证的参数组合**。其中 HI 下限/玉米 HI 配置等属于原型情景选择，不能称为文献直接标定。

上下限通过 RUE 与 HI 同向组合计算，名为“参数情景范围”，不是统计置信区间，也不保证真实产量位于其中。单位为粮食干重，不是某一收获含水率下的商品粮重量。尚不输出混种地块总吨数或逐像元产量图。

## 可靠性与协议

没有实收产量时只能验收数据链路、物理单位、边界处理与产品流程，不能宣称误差率或已达到准确估产。本方法未显式模拟水分/氮素胁迫、品种响应、病虫害和收获损失；光学周期并不等于实际播种/收获日期。当前版本用于完整观测季节的试验回顾估计，未实现生长中季节的最终收获预测。

- Manifest：`simple_yield_estimation=true`，新增 `simple_yield_report`。
- 类型：TaskId/StepId `yield_simple`；旧 `yield` 和 `potential` 含义不变。
- 输入：沿用工作流 AOI、已签名影像快照和可选 `yield_inputs.confirmed_crop_class_id`。作物确认通过现有 `PUT /analysis-workflows/{id}/yield-inputs`，不提供任何必填日期。
- 输出：`estimated_yield_t_ha`、`parameter_scenario_range_t_ha`、`yield_basis=grain_dry_matter`、`experimental=true`、`locally_calibrated=false`、季节/参数/观测/气象来源、限制说明和报告 URI。
- 常见停止原因：`crop_confirmation_required`、`season_in_progress`、`insufficient_observations`、`season_not_identified`、`observation_gap`、`weather_incomplete`。后端不把这些原因映射成模拟成功结果。
- 报告通过 canonical 渲染接口访问，并沿用工作流所有者权限；他人访问返回404。

后续获得实收产量与作物/年份记录后，应建立独立训练/验证集，对区域与品种参数做标定并报告 MAE/RMSE 等指标，再决定是否将试验功能升级为业务估产。
