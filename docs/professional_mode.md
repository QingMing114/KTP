# 工作台专业模式

2026-10-14。专业模式与自动执行为输入区并排、互斥的选项，均默认关闭。咨询、解释、修改草案和进度查询不产生执行确认；明确的分析需求或原任务启动按钮在专业模式下生成参数卡片，确认后调用共享工具服务。

## 交互与执行

1. 没有选片或用户提出新的日期条件时，模型依据同一规划逻辑推荐搜索日期、云量上限，专业模式先暂停。用户修改并确认后才搜索 STAC；无结果保留卡片和编辑值，不放宽条件。
2. 返回候选影像后，用户检查推荐日期、云量与影像 ID，调整影像、任务和 APSIM 运行方式，再确认开始影像准备及任务计算。已有影像则直接从这个确认点开始。任务依赖复用 `planned_steps`，作物识别没有开放可调整的算法参数，20m 和共享波段固定。
3. 有 LAI 或 LAI 依赖任务时，先准备影像并执行已确认的作物识别，然后使用相同的 `configure_workspace_lai` 生成场景参数。专业模式此时登记持久化确认，工作流为 `blocked`，不创建反演子任务、不执行反演，也不启动依赖 LAI 的长势、冠层指数或估产。
4. LAI 卡片显示模型推荐依据与参数来源，可编辑 LAI（0–10）、Cab（0–100）、叶倾角（0–90）、土壤参数（0–1）的范围；未知或用户选择“不限制”为 null。模型不可用或低置信度仍明确展示规则回退，不冒充大模型。
5. 点击确认后，服务端检查范围顺序、有限数值、LUT 可用组合、当前步骤版本及工作台输入，再使用用户值继续同一个工作流。少于10条 LUT 组合的范围保持待确认并提示调整，不静默改为完整 LUT。自动执行保留既有可追溯的范围回退行为。
6. 结果保存实际范围、模型原推荐、确认 ID 和 `user_confirmed` 来源；反演、子任务、报告 JSON 使用同一实际参数。失败重试不会绕过仍在等待的确认。没有 LAI 的任务沿用启动时一次集中确认，以及既有专业资料核验。

## 持久化与边界

- 新增 `WorkspaceContext.professional_mode`，与 `auto_execute` 同时为 true 会被 schema 拒绝。切换选项不改变运行任务的执行模式。
- `ProfessionalReview` 位于工作流 SQLite 的 `product_professional_reviews`，状态为 pending、processing、confirmed、cancelled、failed。原对话 Run 的 `professional_review` part 提供关联，后续卡片从工作台确认列表恢复。
- `GET /workspaces/{id}/professional-reviews` 仅返回当前用户的记录；`POST /professional-reviews/{id}/decision` 接收当前工作台快照和结构化编辑值。状态消费通过 SQLite `BEGIN IMMEDIATE` 串行化，同一确认的成功 HTTP 重放有持久化幂等保护，拒绝请求释放幂等键，用户可修改后再确认。
- 非 LAI 确认绑定完整输入快照，允许相同输入在刷新后使用新 revision；执行过程中仍核验已同步的最新快照。LAI 确认绑定原工作流的不可变影像、AOI、步骤版本与确认 ID。固定配置不能通过自定义字段覆盖。
- 专业模式切换关闭时确认按钮禁用；失效卡片可取消。LAI 卡片取消会停止后续计算并保留已完成步骤。取消仅消费待确认的操作，不声称取消正在运行的算法。
- 页面使用 sessionStorage 恢复未启动专业分析的选区和筛选条件；模式刷新后仍默认关闭，需要用户重新开启。恢复失败的工作流绑定可单独重试，不再提交任务或确认。
- 每轮助手回复下方有独立的“本轮分析记录”，只收录 `source_run_id` 对应本轮且工作区一致的搜索、选片、任务与参数记录；没有对话末尾的汇总入口，也不把其他对话未匹配的记录追加进来。当前轮次且输入仍有效的待确认卡片默认展开；执行工作流完成、失败或取消后，当前轮记录与已结束的阶段详情自动展开。发送新消息时自动收起各轮历史，历史中的待确认表单也默认折叠，并标明待确认或已失效。各入口可独立展开、手动收起，查看历史时保持阅读位置，失效卡片仍禁止执行。
- 折叠只改变显示，不删除服务端记录、不取消任务、不触发确认；组件保持挂载，当前页面内未提交的编辑值在折叠后保留。刷新仍恢复服务端推荐值和已确认参数。未提供系统推送。APSIM 地块资料、简化估产作物确认等仍走原有真实数据检查，不编造气象、土壤、管理或实测事实。
- 本轮历史标注北京时间、任务和已恢复的原始需求。阶段详情展示保存的面向用户的任务理解/规划依据、搜索推荐与确认条件、候选日期/云量/覆盖率及系统推荐说明、用户选片、专业任务依赖与执行状态、固定算法配置，以及 LAI 场景依据和推荐/确认/实际生效范围对比；可打开该工作流的进度与结果。没有保存的说明、范围或执行结果明确标为未记录或未确认，不调用模型补写、不展示内部思维链。实际生效范围只取对应工作流反演记录，不能从确认值推断；取消卡片不声称参数已确认。
- 自动执行和普通任务也提供本轮过程记录：复用已保存的分析计划、参数与关联工作流，展示选片指标/原始说明、实际任务顺序和状态、算法配置、LAI 配置依据与配置/生效范围。当前轮在工作流结束或自动任务暂停需要输入时直接展开，不依赖专业模式开关；新消息到来后收起，手动收起在本轮内保留。刷新可展示已有任务，不重跑、不补造候选列表或搜索条件；清空列表的隐藏设置仍优先。

## 助手历史列表的显示设置

助手标题下方新增“清空列表”：只隐藏当前可清理的历史消息、对应的本轮分析记录及已完成的独立任务回执。正在回复、提交或确认时不可清空；运行中任务和当前等待补充/参数确认的轮次保留。左侧分析面板、对话 ID、模型上下文、任务、确认记录和报告不变，不调用删除或取消接口。

隐藏设置按登录用户与工作区保存在此浏览器的 localStorage 中，以 Run/任务 ID 识别，刷新恢复历史时事件 ID 改变也不会重新显示；之后新增轮次正常显示。点击“恢复历史”恢复当前对话的已隐藏记录，不影响其他对话的显示设置。组件不卸载隐藏记录，因此本页面内的未提交编辑值保留；浏览器存储写入失败会明确报错，不假装已保存。该设置不跨浏览器同步。


## 验证

受控 API 测试覆盖搜索前暂停、用户搜索条件、选片与任务编辑、并发确认、幂等、撤回模式、变更输入、取消、咨询和恢复。LAI 测试使用实际 PROSAIL 反演与可控 LUT：模型推荐4–5，用户确认0–2后得到对应的 LAI 1，报告记录确认范围且保留原推荐。浏览器验证覆盖并排互斥、编辑、确认与刷新，桌面及手机布局均需检查。部署记录见 `deploy/professional_mode_validation.json`。
