## 项目简介

KTP（Knowledge Transfer Platform）产品后端是一个遥感/农业领域的多智能体系统，提供从数据接入、推理、训练到报告生成的全链路能力。

### 核心特性

- 🔍 **遥感推理** — 秃斑检测、LAI 反演等遥感分析
- 📊 **模型训练** — Temporal 工作流驱动的 ML 管道
- 📝 **RAG 检索** — 向量化文档检索增强生成
- 📈 **可视化** — 自动生成分析图表和报告
- 🤖 **多智能体** — LangGraph 编排的多 Agent 协作
- 💬 **聊天界面** — 自然语言交互的产品协议

## 快速开始

### 安装

```bash
cd ktp/backend/
pip install -e .
```

### 启动服务

```bash
cd ktp/backend/
python -m uvicorn app.main:app --host 0.0.0.0 --port 18180 --reload
```

或使用脚本：

```bash
cd ktp/backend/
python scripts/start_product_backend.py
```

服务默认监听 `http://127.0.0.1:18180`。

### 访问界面

- 健康检查: `http://127.0.0.1:18180/health`
- API 文档: `http://127.0.0.1:18180/docs`

## 核心模块

### API 网关

API 网关是系统的统一入口，提供以下路由：

| 路由 | 说明 |
|------|------|
| /v2/chat | 聊天交互 |
| /v2/conversation | 会话管理 |
| /v2/detect | 目标检测 |
| /v2/workflow | 工作流管理 |
| /v2/report | 报告生成 |
| /v2/visualization | 可视化 |
| /v2/artifacts | 制品管理 |
| /health | 健康检查 |

### 查询引擎

查询引擎是任务执行的核心，负责：

- 任务调度和执行
- 循环和重放
- 委派和失败处理
- 思考解析和状态管理

### 产品协议

产品协议定义了与前端交互的规范：

- 路由协议
- 会话协议
- 制品协议
- 幂等性协议
- 错误协议

## 配置说明

### 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| KTP_HOST | 0.0.0.0 | 服务监听地址 |
| KTP_PORT | 18180 | 服务监听端口 |
| KTP_JWT_SECRET | ktp-dev-... | JWT 密钥（生产环境必须修改） |
| KTP_DATA_DIR | ./var | 数据目录 |
| KTP_LLM_BASE_URL | http://127.0.0.1:8000/v1 | LLM API 地址 |

### 运行时数据路径

| 路径 | 说明 |
|------|------|
| var/runtime | 运行时状态 |
| var/gateway | 网关数据 |
| var/rag | RAG 索引 |
| var/artifacts | 制品存储 |
| var/training | 训练数据 |
| var/ml | ML 模型 |
| var/llm | LLM 缓存 |

## API 接口

### 聊天接口

```bash
curl -X POST http://localhost:18180/v2/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "分析这张遥感影像中的秃斑区域",
    "session_id": "session-001"
  }'
```

### 会话管理

```bash
# 创建会话
curl -X POST http://localhost:18180/v2/conversation \
  -d '{"title": "遥感分析任务"}'

# 获取会话列表
curl http://localhost:18180/v2/conversation
```

### 目标检测

```bash
curl -X POST http://localhost:18180/v2/detect \
  -F "image=@/path/to/image.tif" \
  -F "model=baldness_rf"
```

## 领域服务

### 推理服务

提供遥感影像推理能力：

- 秃斑检测（Baldness RF）
- 自定义模型推理
- 预处理和后处理管道

### 训练服务

基于 Temporal 工作流的 ML 训练管道：

- 数据准备
- 模型训练
- 评估和验证
- 模型注册

### RAG 服务

检索增强生成服务：

- 文档向量化
- FAISS 向量存储
- 语义分块
- 重排序

### 报告服务

自动生成分析报告：

- HTML/PDF 报告
- 图表生成
- 模板系统

### 可视化服务

生成分析可视化：

- 预测结果可视化
- 置信度地图
- 仪表盘

## PROSAIL 遥感模型

PROSAIL 是叶片光学特性模型（PROSPECT）和冠层双向反射模型（SAIL）的耦合模型，用于植被参数反演。

> 注：PROSAIL 相关代码需要单独安装依赖。

## 常见问题

### Q: 启动时报 skimage 模块缺失？

```bash
pip install scikit-image
```

### Q: 如何修改默认端口？

```bash
export KTP_PORT=18080
python -m uvicorn app.main:app --port 18080
```

### Q: JWT 密钥警告？

生产环境必须设置强密钥：

```bash
export KTP_JWT_SECRET="your-strong-secret-key"
```

### Q: 如何连接不同的 LLM？

```bash
export KTP_LLM_BASE_URL="https://api.openai.com/v1"
export KTP_LLM_API_KEY="sk-xxx"
```
